# C++ Text Dungeon Engine

A text-based adventure engine written in C++ demonstrating structured data, reference parameters, and state-based room navigation.

## 🚀 Features
- **Player State Management:** Custom `Hero` struct tracking HP, inventory keys, and room positioning.
- **Pass-by-Reference Architecture:** Efficient room state mutations without unnecessary memory allocation.
- **Interactive Game Loop:** Branching path logic with room search mechanics.
